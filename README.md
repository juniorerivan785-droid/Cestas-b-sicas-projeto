# Cestas-b-sicas-projeto
A história do projeto Cesta Básica  Em nossa comunidade, existem famílias que passam por momentos difíceis e, muitas vezes, precisam escolher entre comprar alimentos e atender outras necessidades básicas.  Pensando nessas famílias, surgiu o Projeto Cesta Básica, uma iniciativa da Pastoral da Caridade da Igreja Católica de Guanambi.
